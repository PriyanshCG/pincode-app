# 📍 Pincode Explorer (Full Stack Project)

A full-stack web application to explore Indian PIN code data with advanced filtering, search, and analytics.

---

## 🚀 Features

- 🔍 Search pincodes by keyword
- 🌍 Filter by State → District → Taluk
- 📊 Dashboard stats (Total, Delivery, Non-Delivery)
- 📈 State-wise & Delivery distribution
- 📄 Pagination support
- ⬇️ Export data as CSV
- ⚡ Fast UI with React + Tailwind

---

## 🛠️ Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
